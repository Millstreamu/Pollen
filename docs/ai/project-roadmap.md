# Project Roadmap — Small-Seller ERP

## Roadmap Objective
Deliver a practical V1 app for small sellers with clear workflows for orders, stock, making, buying, and simple money visibility.

## Milestone 1 — App Shell and Navigation (Definition Only)
Status: pending

Scope:
- App shell structure
- Primary navigation for: Today, Orders, Products & Stock, Make / Buy, Money, Settings
- Basic layout and placeholder pages only

Explicitly excluded:
- Business logic
- Workflow automation
- Integrations
- Advanced UI behavior

## Milestone 2 — Orders Foundation
Status: pending

Scope:
- Basic order model and status tracking
- Reserve → pack → ship state flow
- Simple order list/detail operations

## Milestone 3 — Products & Finished Stock
Status: pending

Scope:
- Product catalog basics
- Finished stock tracking and adjustment
- Reservation impact from orders

## Milestone 4 — Materials and Purchasing
Status: pending

Scope:
- Material catalog
- Purchase creation and receiving
- Material stock increment on receiving

## Milestone 5 — Make / Batch Workflow
Status: pending

Scope:
- Batch make records
- Material decrement on make
- Finished stock increment on completion

## Milestone 6 — Today Dashboard
Status: pending

Scope:
- Action-oriented summary cards
- Late/urgent order attention
- Low stock and open operational tasks

## Milestone 7 — Money (Simple Estimates)
Status: pending

Scope:
- Basic sales totals
- Simple estimated profit view
- No advanced accounting/tax rules

## Milestone 8 — Stabilization and Release Readiness
Status: pending

Scope:
- Validation and edge-case hardening
- Documentation and milestone completion checks
- Final V1 polish within defined scope
