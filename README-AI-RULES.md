# AI Development Rules Kit

Start with `AI_DEVELOPMENT.md`.

Recommended short Codex prompt:

```text
Read AI_DEVELOPMENT.md.
Implement <issue/milestone/bug plan>.
```

The repo files hold the rules. The prompt only points Codex to the task.

## Core Folders

- `docs/ai/` — rules, memory, reports, decisions
- `docs/ai/templates/` — reusable templates
- `docs/ai/bugfix-plans/active/` — active multi-chat bug plans
- `docs/ai/bugfix-plans/completed/` — completed bug plans
- `.github/` — issue/PR/CI templates
